# 16位RISC CPU指令集架构

本项目是一个16位精简指令集计算机（RISC）CPU的指令集架构（ISA）设计文档。

## 项目概述

这是一个采用前缀分层编码方案的16位定长指令集架构设计，包含以下核心特性：

- **架构类型**：RISC（精简指令集计算机）
- **指令字长**：16位定长
- **寄存器组**：16 × 16位通用寄存器（GPR）
- **编码方式**：前缀分层扩展编码
- **字节序**：小端序（Little-Endian）

## 项目内容

- `ISA_Outline.md` - 英文版的指令集架构设计大纲
- `ISA_Outline_zh.md` - 中文版的指令集架构设计大纲

## 主要特点

1. **分层编码架构**：通过2位→8位→12位三级前缀解码层次，在固定16位宽度内支持多种指令格式
2. **寄存器寻址型指令**：支持三寄存器算术/逻辑运算和加载/存储操作
3. **Load/Store优化**：采用4+4寄存器分区（专用L/S寄存器和基址寄存器）的平衡设计
4. **LUI类指令**：支持高位立即数加载，便于构建完整16位地址
